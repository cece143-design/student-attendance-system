Student Attendance Management System
Project Description

This project is a Python console application that helps manage attendance for 10 students.

Features
Display all students.
Search for a student using their ID.
Mark attendance as Present, Absent, or Late.
Calculate attendance percentage.
Display attendance summary.
Correct the latest attendance record.
Validate user input.
Python Concepts Used
Variables and data types
Input and output
Operators
If, elif, and else statements
For and while loops
Functions
Match-case statements
How to Run
Open attendance_system.py in Python 3.10 or newer.
Run the program.
Choose an option from the menu.
Limitation

Attendance records are stored temporarily and reset when the program restarts.
